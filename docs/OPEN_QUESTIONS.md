# Відкриті питання

Ці питання не потрібно повторювати користувачу всі одразу. Codex спочатку читає
доступне середовище/репозиторій. Питання майбутніх модулів не блокують поточний етап.

| ID | Що невідомо | Коли потрібно | Безпечний default |
|---|---|---|---|
| Q01 | Repo URL/owner/visibility | До remote push | Local only, repo_url=null |
| Q02 | Ліцензія/бренд | До public release | Working title, без LICENSE claim |
| Q03 | Actual macOS/доступні dependencies | M0/install | Read-only environment report |
| Q04 | Codex model catalog/auth/effort/retention/дозволений runtime use | M0/M3 | Mock/OFF, без live call |
| Q05 | MiniMax actual plan/seat/route/Credits handling | Перед MiniMax | OFF |
| Q06 | Private HTTPS/DNS/transport для Android | M2 | Synthetic only, manual encrypted export fallback |
| Q07 | Точна модель wearable і версії apps | M6 | Wearable disabled |
| Q08 | Згода власниці на кожний data flow і retention | Перед реальними даними | LOCAL_ONLY; ніякого seed import |
| Q09 | Account cloud backups/Samsung sync/OS dictation | Перед private use | Видиме попередження, перевірка налаштувань |
| Q10 | Клінічний reviewer і права на протоколи | До M7 activation | Protocol flags OFF |
| Q11 | Детальні game/film preferences, візуальний стиль | M5 | Нейтральний UI, optional cosmetic layer |
| Q12 | Backup location і key recovery | До private rollout | Synthetic data only до перевіреного restore |
| Q13 | Поза-домашній remote access | Після M2 за потреби | Sync тільки у доступній приватній мережі |

MacBook Air M2/16 GB і Galaxy S24 Ultra вже задані. Не питати модель телефона або
обсяг RAM повторно. Не вгадувати точний рік/macOS за приблизним роком придбання.
Приватні симптоми не запитувати для виконання технічного M0.
