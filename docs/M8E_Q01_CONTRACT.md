valid; record that gap, never mark them safe because controller state is COMPLETED. Do not silently alter hard
safety/consent/crypto/sync gates to improve a score. Neutral wording changes can influence observed replies but
cannot establish fail-closed semantic safety or therapeutic benefit.

Executor ratings are preliminary LLM assessments. Historical unequal corpora and model/effort versions remain
distinct. No automatic winner; use INCONCLUSIVE where evidence is weak. Candidate clinical questions/proposals
are evaluation artifacts, never treatment procedures or runtime instructions. Qualified independent content,
rights, evidence and separate activation reviews remain required.

record current profiles as NOT_EVALUATED/INCONCLUSIVE; historical masked samples remain explicitly historical.
