# Інтерфейс, творчість, гейміфікація та фідбек

## Навігація

Початкові розділи: Сьогодні · Щоденник · Творча полиця · Практики · Огляд.
Налаштування доступні окремо. На телефоні одна головна кнопка «+».

Capture sheet: текст або мікрофон → необов’язковий тип → зберегти.
Типи: «Думка/розвантаження», «Сон», «Самопочуття», «Творча ідея», «Нотатка з книги/фільму»,
«Вправа», «Відгук про застосунок». Без AI запис не блокується: він потрапляє в Inbox.
Система може запропонувати тип/теги пізніше, але не змінює авторський зміст мовчки.

Збереження не запускає психологічний аналіз автоматично. Відповідь «Записано» часто
доречніша за десять уточнень. Є режим «лише зберегти, без обговорення».

## Простота і доступність

Один фокус на екрані, поступове розкриття полів, великі touch targets, keyboard access,
контраст, reduced motion, добрий український текст. Без блокуючих onboarding-анкет.
Чернетка зберігається локально; ясно видно offline/sync/AI states. Помилка не стирає введене.
Не показувати все життя в десятках шкал; default dashboard містить кілька погоджених метрик.

## Творча бібліотека

Ідеї можуть бути сценою, персонажем, темою, фразою, кадром, списком, reference або власним
типом. Почати з тегів/колекцій і простих зв’язків, не зі складного графа знань.
Оригінал недоторканний; AI summary, dedup suggestion і категорії — окремі поля.
Можна швидко знайти «ідеї для короткометражки» або зробити вибраний export для іншої AI.
Не копіювати повні книги, субтитри або copyrighted сценарії до public research.

Розвантаження думок і Kaizen-подібні маленькі кроки — UX-ідеї, не заяви про
клінічну ефективність. Перетворення нотатки на завдання потребує згоди;
не перетворювати кожну творчу ідею на дедлайн або борг.

## Гра без тиску

Можлива метафора: затишна творча кімната/студія, колекція власних персонажів,
необов’язкові декорації, персоналізація. Точну тему обрати після переліку вподобань.
Sims — референс інтересу до симуляцій, не дозвіл копіювати персонажів, UI чи assets.

Дозволені винагороди: косметичний предмет за добровільну корисну дію, вибір кольору,
побудована полиця ідей. Можливий нейтральний режим без гри з тими самими функціями.
Немає втрати прогресу за пропуск, «вмираючого улюбленця», штрафу за поганий сон,
streak shame, loot boxes, leaderboard або повідомлень «ти мене покинула».
Не нагороджувати за інтенсивність симптомів, кількість розкритих таємниць або щасливу
самооцінку. Відпочинок/пауза — повноцінний вибір, не спосіб «зламати» гру.

## Межа «ідея» / «фідбек»

Творча/особиста ідея завжди private. Категоризація не дає права опублікувати її.
Product-feedback draft може бути створений вручну або за явним проханням.
Розробники отримують не весь щоденник, а затверджену користувачкою редакцію.

Вкладка фідбеку показує: заголовок, очікуваний результат, що незручно, кроки відтворення,
редагований очищений опис, видимість, одержувача. Поділ на bug/feature/design не міняє privacy.
Спочатку реалізувати export Markdown для ручної передачі. GitHub issue publication —
опційний етап із окремим auth і review. Runtime сам не пушить код або нотатки у Git.

## Тестування навантаження

Після практики можна коротко позначити «допомогло / нейтрально / стало важче / пропустити».
Підвищене відстеження, самокритика або небажання продовжувати — сигнал спростити продукт,
не додати ще завдань. Немає «ідеальної користувачки», для якої треба оптимізувати метрики.
