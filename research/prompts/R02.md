# R02 — Щоденники сну, стану та мінімальні вимірювання

Status: NOT_STARTED · Priority: P0 · Product dependency: M1 data contract; M7 content.

Цей файл разом із `research/MASTER_RESEARCH_PROMPT.md` є самодостатнім завданням
для research-моделі. Загальна мета: доказово спроєктувати конкретну частину local-first
щоденника й самодопомоги, без персональних даних і без вигаданих клінічних висновків.

## Питання

Перевірити Consensus Sleep Diary та альтернативи; розрізняти self-report, wearable estimate й objective clinical measurement. Дослідити time-in-bed, estimated sleep, пробудження, відновлення, distress; правила записів через північ, пропусків, ретроспективного внесення. Яка мінімальна форма корисна без надмірного відстеження? Які шкали мають валідовані українські версії та права використання? Не вважати довільний переклад валідованим.

## Очікуваний продуктово-корисний вихід

Data dictionary з визначеннями/одиницями/optional полями, коротка та розгорнута форми, правила missing data, licensing matrix. Діагностичні cutoffs не активувати без review.

## Не пропустити

Точна популяція/формат або supported platform/version; сильні й слабкі докази;
negative/null results або engineering failure modes; adverse effects/privacy risks;
границі застосування; точні джерела та доступність full text; права на файли/переклади.
Для технічної теми не вигадувати клінічну evidence table, а дати відтворюваний test plan.

## Формат

Короткий висновок для архітектора, evidence/design matrix, sources з датою перевірки,
обмеження й невирішені питання, candidate protocol/design, eval cases, rights note.
Будь-який protocol є DRAFT до окремого review. Не ставити ACCEPTED за себе.

## Критерій завершення

Архітектор може побачити, що саме дозволено реалізувати, що ще не відомо, які
джерела підтримують кожний важливий claim і які tests/gates повинні передувати активації.
